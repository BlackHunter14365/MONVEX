# MONVEX Windows Desktop — Keyboard Shortcuts Reference

**Version**: 2.0.0  
**Platform**: Windows 10 / 11 Desktop  

---

## 1. Global System Hotkeys

| Shortcut | Scope | Action | Description |
| :--- | :--- | :--- | :--- |
| **`Ctrl + K`** (or `⌘K`) | Global | **Command Center** | Opens the universal search palette across all financial records and commands. |
| **`Ctrl + N`** | Workspace | **Quick Transaction** | Opens the fast transaction ingestion modal dialog. |
| **`Ctrl + Shift + A`** | Workspace | **AI Copilot** | Routes immediately to the MONVEX AI reasoning workspace. |
| **`Esc`** | Workspace | **Dismiss / Close** | Closes any active modal, command palette, or overlay. |

---

## 2. Command Center Navigation

| Key | Context | Action |
| :--- | :--- | :--- |
| **`↑` (Arrow Up)** | Command Center | Moves selection to the previous search result. |
| **`↓` (Arrow Down)** | Command Center | Moves selection to the next search result. |
| **`↵ Enter`** | Command Center | Executes the selected navigation or quick action. |
| **`Esc`** | Command Center | Closes the Command Center and returns focus to workspace. |

---

## 3. Financial Ledger Shortcuts

| Shortcut | Context | Action |
| :--- | :--- | :--- |
| **`Ctrl + E`** | Ledger / Settings | Triggers CSV / JSON export of transaction history. |
| **`/`** | Transactions | Focuses search query bar in transactions table. |

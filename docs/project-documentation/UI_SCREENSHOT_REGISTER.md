## 3. UI Component Structure & Interaction Documentation

For each major screen, the primary interactive components and state transitions are summarized below:

### 3.1 Dashboard (`UI-03`, `UI-04`)
* **Key Components:**
  - `NetWorthCard.tsx`: Renders total assets minus liabilities with percentage delta indicator.
  - `CashFlowSummary.tsx`: Dual-column card showing total income, total expenses, and net savings.
  - `CategoryDonutChart.tsx`: Interactive Recharts donut visualization with tooltips and category legends.
  - `HealthScoreWidget.tsx`: Circular animated radial gauge displaying the 0–100 score and grade badge.
  - `RecentTransactionsList.tsx`: Condensed 5-row table with quick links to full ledger.
* **States:** Full data state, skeleton loading animation during TanStack query fetch, empty state with onboarding CTA.

### 3.2 Transaction Management (`UI-05`, `UI-06`)
* **Key Components:**
  - `TransactionList.tsx`: Virtualized list displaying date badges, category pill icons, merchant titles, and green/red formatted amounts.
  - `AddTransactionModal.tsx`: React Hook Form with Zod schema validation; supports single-click NLP parsing.
  - `TransactionFilters.tsx`: Search bar, date range picker, category dropdown, and type segment toggle.
  - `ExportCSVButton.tsx`: Triggers binary stream download of RFC 4180 CSV file.

### 3.3 AI Copilot Workspace (`UI-07`, `UI-08`)
* **Key Components:**
  - `DesktopAIWorkspace.tsx`: Split-screen layout featuring conversation thread on the left and live financial context inspector on the right.
  - `AIMessageRenderer.tsx`: Full GitHub-flavored markdown renderer with syntax-highlighted code and interactive embedded widgets (e.g., mini cashflow charts).
  - `FinancialCommandBar.tsx`: Quick query suggestions (e.g., *"How much did I spend on dining this week?"*, *"Simulate paying off my loan 6 months early"*).
